# professional-learning-report-progress-tool

This repository was created as part of my software development tools learning activity for 43030 Professional Practice in Computing.

## Purpose

The purpose of this checklist is to track my progress in completing my Professional Learning Report evidence, including cybersecurity activities, GitHub activities, ethical practice evidence, Portfolium updates and reflection writing.

## Checklist

- [x] Cybersecurity Quiz 1 completed
- [x] Cybersecurity Quiz 2 completed
- [x] Cybersecurity Assessment 3 submitted
- [x] GitHub Essentials Quiz completed
- [x] GitHub Workflow Quiz completed
- [ ] Ethics module evidence collected
- [ ] Indigenous Professional Capability evidence collected
- [ ] Portfolium updated
- [ ] Reflection section written
- [ ] Future goals written

## Reflection

This activity helped me understand how GitHub can be used not only for code storage, but also for tracking progress, documenting work and managing changes. This is relevant to my future Business Analyst pathway because Business Analysts need to document requirements, track project progress, communicate updates and understand how technical teams manage work.
